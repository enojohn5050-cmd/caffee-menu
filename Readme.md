# The Golden Bean — Cafe Menu Website

A client-ready cafe menu website built with pure HTML and CSS.

## Live Demo

[View live site]{https://github.com/enojohn5050-cmd/caffee-menu}

---

## What this is

A fully designed cafe menu website I built as a client pitch demo.
It shows cafe and restaurant owners exactly what their website could look like
if they hired me to build it.

---

## What's on the page

- A dark-contrast card that pops off the screen
- Drinks section with names, descriptions and prices
- Desserts section with clear spacing from the drinks
- Prices pinned to the right with amber badge styling
- Header and footer in matching dark brown
- A pitch strip at the bottom for potential clients

---

## Built with

- HTML5
- CSS3 (Flexbox for layout)
- No JavaScript
- No frameworks or libraries

---

## What I learned building this

- How `display: flex` and `justify-content: space-between` pins items to opposite sides
- How to use `section + section` to add spacing between sections
- How colour contrast makes a design stand out (dark wrapper vs light card)
- How to turn a practice exercise into a real client pitch

---

## How to run it locally

Download the files, then open `index.html` in your browser. That's it.

```
cafe-menu/
├── index.html
├── styles.css
└── README.md
```
